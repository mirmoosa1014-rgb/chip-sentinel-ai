# Project summary

ChipSentinel is an educational digital diagnosis laboratory with a versioned 4-bit ALU simulator, separate synchronous register bank, deterministic fault injection, consistency baseline, trained logistic candidate ranker, entropy-based test policy, paired experiments, and an interactive 3D React workbench.

Truthful resume bullet after personally reviewing and reproducing it: “Directed an AI-assisted digital fault-diagnosis laboratory; evaluated consistency and learned candidate ranking on held-out synthetic ALU topologies with reproducible experiments and interactive visualizations.” Do not claim independent authorship, silicon validation, or improvement from ML-driven active selection.
