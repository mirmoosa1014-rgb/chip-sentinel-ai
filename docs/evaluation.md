# Evaluation

Reproduce `python -m chipsentinel.experiment --full`. This regenerates the model using only training families, then runs fixed/random/active policies on identical test-family/fault episodes with equal eight-vector budgets. The fixed vector pool begins with corner values interleaved across all four ALU operations, followed by seeded random vectors. No policy sees the hidden fault. Fault-table consistency is a deterministic non-ML baseline; compare its top-1/top-3 with learned ranking on the same evidence.

Raw per-episode data includes exact-hypothesis top-1/top-3, equivalence-aware top-1, residual candidates, and censored test effort. Metrics JSON includes three failed learned predictions, observations, true labels and predictions. Equivalent signatures are computed across the bounded 48-vector pool, so equivalence here is pool-relative rather than proof over all possible vectors. No-fault specificity is evaluated on only two unique deterministic circuits and must not be interpreted as a statistical real-world false-alarm rate. Runtime is measured end to end on the local machine and is not a cross-machine benchmark.

Whole topologies, not vectors, are split. No family is repeated between training and test, though all implement the same arithmetic and share primitives. The test pool is known to the policy as candidate experiments, which is legitimate for exact-model active diagnosis. It is not leaked hidden episode truth. Synthetic observations are noiseless. Sensor noise, transistor-level defects, fault timing, calibrated uncertainty and real-world domain shift are outside scope.
